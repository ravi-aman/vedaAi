## 10. Fallback logic

| Aspect | Current state |
|--------|---------------|
| Provider fallback chain | **None.** Single provider. If OpenRouter fails, no `tryProviderChain()` to try NVIDIA or OpenCode. |
| Credit handling | `verifyVisionPreflight()` + `visionStageWithShared()` detect `status 402` / `credit_exhausted` and **pause queue** (`pausedDueToCredit = true`, break). Does not try alternate provider. |
| Retry on 402 | No retry — treated as `retryable: false` (openrouter-vision.ts:142-145, 169-170). |

Non-retriable (`401/403`, `404`, `400`) throws immediately. ## 11. Preflight

**File:** `src/lib/vision/openrouter-vision.ts:35-122` (`verifyVisionPreflight`)

1. Check key missing → `{ ok:false, reason: "OPENROUTER_API_KEY missing" }`
2. `GET {sanitizedBase}/key` (8000ms timeout) → if `limit_remaining < 5000` → fail insufficient credits (needs ~70000). If `401/403` → auth fail. 404 → fall through.
3. `GET {sanitizedBase}/models` (8000ms) → warn if model not found, but **not blocking**.
4. Cheap probe: `client.chat.completions.create({ model, messages:[{text:"ping"}], max_tokens:10 })` (12000ms) → if `402` → credit fail, `401/403` auth, `404` model not found → fail; `429/5xx` → warn but return `ok:true` (don't block).

Runner calls `verifyVisionPreflight()` before global scheduler (runner.ts:846). If `!pre.ok`, writes `vision-preflight.json` to `os.tmpdir/veda-ai/{jobId}/debug` and `artifacts/debug/{jobId}/vision-preflight.json`, sets `globalThis.__visionPreflightFail` map, marks both docs `vision: failed`.

**Gaps:**
- Only OpenRouter; not provider-agnostic. No `VisionProvider.preflight()` method on interface.
- No typed `VisionPreflightResult` (`ok, provider, model, available, reason, latencyMs`).
- No generic capability declaration.

## 12. Retry behavior

| Layer | Policy |
|-------|--------|
| `openrouter-vision.ts:withRetry` | `max 3`, classify `429/5xx/408` as retryable, `401/403/402/404/400` non-retryable. Delay `Math.pow(2, attempt)*600 + random*400`. Logs `provider, model, endpoint, status, errorType, retryCount`. |
| `openrouter.ts:withRetry` (AI, not Vision) | Similar but also handles `429/5xx/timeout`. Delay `2^attempt*600 + random*400`. |
| `runner.ts:visionStageWithShared` per-batch | Outer loop catches `isCredit` → `pausedDueToCredit` + 2s wait + break. `isMalformed` → `failedRequests++`. `isRetriable (429/408/5xx)` → if `auto`record empty array, else throw. |
| OCR (`runner.ts:ocrStageWithShared`) | Separate PaddleOCR retry (maxRetries 2, backoff `2^attempt*400 + jitter`). Not part of Vision fallback. |
| `getConfig()` retry | Bounded retry (max 3, exponential backoff + jitter) on `MODEL_OUTPUT_INVALID` for malformed JSON — one retry with same input (lines 302-323, 368-388). |

No `VISION_MAX_RETRIES` env (hardcoded `3`), no `VISION_TIMEOUT_MS` per-provider.

## 14. Response parsing

**Steps (per `analyzePage` / `analyzeDocumentStructure`):**
1. `stripFences(t)` — remove ```json fences
2. `extractJsonObject(raw)` — balanced brace scan handling escapes
3. `JSON.parse(contentStr)` — if fails, `saveMalformedRawArtifact(label, raw, error)` to `os.tmpdir/veda-ai/vision-malformed` + `artifacts/vision-malformed`, log `vision_malformed_json`, bounded retry once. If retry also fails → `AppError(MODEL_OUTPUT_INVALID, parse failed)`.
4. `VisionPageStructureSchema.safeParse(parsed)` / `VisionDocumentAnalysisSchema.safeParse` — Zod validation (lenient: `type` optional fallback to `regionType`/`label`, `relatedQuestionLabel` nullable, `blockIds` default `[]`, `coarseBox` optional, confidence default 0.7). If schema invalid → save artifact, try single-page fallback, else throw `MODEL_OUTPUT_INVALID`.
5. No provider-specific response shape leakage beyond normalization via Zod transforms + `normalizeRegionType`.

**Vision provider interface schemas** (`provider.ts:8-143`): `KNOWN_REGION_TYPES` (14 entries), `VisionPageStructureSchema`, `VisionDocumentAnalysisSchema`, `VisionAnalyzePageInput` (pageId, pageNumber, imageBase64, mimeType, ocrBlocks, width/height), `VisionAnalyzeDocumentInput`, `VisionProvider` interface + `VisionConfigSchema` (legacy, not used in production).

## 16. Four-way parallel invariant (must preserve)

```
QP OCR       ║
AS OCR       ║   ← ocrStageWithShared: Promise.all([runDocWithRetry("questionPaper"), runDocWithRetry("answerSheet")])
QP Vision    ║
AS Vision    ║   ← visionStageWithShared: global queue but launched via Promise.all([ocrPromise, visionPromise]) with shared render predecessor
```

- `renderSharedStage` runs once (`Promise.all` QP+AS render to `paddle-images/...`), produces `SharedPageImage[]` (path + dims, base64 lazy).
- `Promise.all([ocrPromise, visionPromise])` (runner.ts:339) proves **OCR || Vision never serialized**. Vision is `image-first` (no OCR dependency for Pass 1).
- Vision global scheduler (`globalConcurrency=1`) processes QP+AS batches sequentially after render, but still parallel to OCR.
- Changing provider selection **must not** reintroduce `OCR → Vision` serialization.
